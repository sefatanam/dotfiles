SketchyBar

Custom menu bar at the top of the screen.

What I set

  • 40px bar, slightly see-through and blurred.
  • One chip per AeroSpace workspace, showing app icons instead of names.
  • Shows the focused app, battery, volume and clock.
  • Sits below the macOS menu bar, so Wi-Fi and Control Center stay clickable.

  • Status bar turns green while the prefix is active.

A key goes to the outermost layer first. AeroSpace takes Alt keys, Ghostty takes Cmd keys, tmux takes anything after its prefix, and the rest reaches Neovim or zsh.

Start here

git clone https://github.com/sefatanam/dotfiles ~/.dotfiles && cd ~/.dotfiles && ./setup.sh
Set up a new Mac. Add --dry-run to only preview.
./setup-validate.sh
Check that links, configs and these pages are all correct.
./update-keybindings.sh
Run after changing a key. Rebuilds the key tables on this page.
transparency toggle
Turn transparent mode on or off for Ghostty, tmux and Neovim together. Restart Ghostty after.

Gotchas

Cmd+B zoom relies on a tmux default

It sends prefix + z. My config never sets z, so if tmux changes its defaults, the key stops working without any error.

Cmd+S splits, it does not save

It sends prefix + s, which splits the pane into a top and bottom half.

tmux split names look backwards

split-window -h puts panes side by side. -v stacks them.

Space does nothing alone in Neovim

It is the leader key. A bare Space waits for the next key.

prefix + Ctrl+r restores a session

The config also binds it to the yazi file manager, but tmux-resurrect loads later and takes the key, so yazi cannot be opened from any key.

Transparent mode is one switch

Never turn it on in just one tool. Use transparency so Ghostty, tmux and Neovim stay in sync.
